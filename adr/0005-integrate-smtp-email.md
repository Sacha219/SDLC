# Использование SMTP для отправки email-уведомлений

## Контекст и постановка задачи
Ученикам необходимо отправлять подтверждения об успешной записи на тренировку, а также напоминания о предстоящих занятиях. Какую технологию выбрать для отправки писем?

## Драйверы решения
1. **Простота реализации:** Решение должно быть реализовано быстро.
2. **Надежность:** Письма не должны теряться при сбоях.
3. **Стоимость:** Использование бесплатных или дешевых сервисов на старте.

## Рассмотренные варианты
* Прямая интеграция с API почтовых сервисов (SendGrid, Mailgun).
* Использование стандартного протокола SMTP через встроенные средства Java.

## Итог решения
Выбран вариант **«Использование SMTP»**. Это стандартный протокол, который поддерживается любым почтовым сервером и не требует сложной интеграции.

### Последствия
* **Хорошо:** Реализация проста и надежна, использует встроенный `JavaMailSender`.
* **Хорошо:** В будущем легко заменить на любой платный сервис.
* **Плохо:** Без настройки DKIM/SPF письма могут попадать в спам.

### Подтверждение
Проверка наличия зависимости `spring-boot-starter-mail` в `pom.xml`. Наличие конфигурации SMTP в `application.yml`.

## Плюсы и минусы вариантов

### Прямая интеграция с API (SendGrid, Mailgun)
* **Хорошо:** Более высокая доставляемость писем из коробки.
* **Плохо:** Требует настройки аккаунта и может стоить денег.

### Использование SMTP
* **Хорошо:** Бесплатно, стандартно, легко настроить.
* **Плохо:** Может потребовать ручной настройки почтового сервера.

## Дополнительная информация
