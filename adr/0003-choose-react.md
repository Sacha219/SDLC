# Использование React для клиентской части

## Контекст и постановка задачи
Необходимо создать быстрый и интерактивный интерфейс, который будет обновляться без перезагрузки страницы (например, при фильтрации расписания по филиалам). Какую библиотеку выбрать для Frontend?

## Драйверы решения
* **Скорость работы:** Высокая производительность рендеринга (Virtual DOM).
* **Переиспользование:** Создание переиспользуемых UI-компонентов (карточки занятий, фильтры).
* **Сообщество:** Большое количество готовых решений и библиотек.

## Рассмотренные варианты
* React
* Vue.js
* Angular

## Итог решения
Выбран вариант **«React»**, потому что он обеспечивает высокую скорость работы и позволяет легко разбивать интерфейс на компоненты.

### Последствия
* **Хорошо:** SPA-приложение работает быстро и плавно.
* **Плохо:** требует настройки дополнительных библиотек (React Router для навигации).

### Подтверждение
Проверка наличия файла `package.json` с зависимостями `react` и `react-dom`.

## Плюсы и минусы вариантов
### React
* **Хорошо:** огромное сообщество, высокая скорость.
* **Плохо:** требует изучения дополнительных библиотек.

### Vue.js
* **Хорошо:** простой синтаксис.
* **Плохо:** меньшее сообщество.

### Angular
* **Хорошо:** полноценный фреймворк.
* **Плохо:** сложный и тяжелый.

## Дополнительная информация
Адресует требования SRS: REQ-INT-001 (главная страница), REQ-INT-002 (личный кабинет). Связано с ADR-002 (Spring Boot).
